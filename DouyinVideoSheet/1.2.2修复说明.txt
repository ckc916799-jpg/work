1.2.2：修复抖音图文页没有悬浮面板

原因：1.2.1 只把 /video/、modal_id、aweme_id 地址识别为当前作品；/note/ 图文详情返回空 ID，面板因此被隐藏。

修复：
- bridge.js 与 observer.js 同时识别 /video/ 和 /note/。
- 图文页无 video 元素时仍可读取详情页 DOM 和元信息。
- 图文 API 数据的首图可作为封面链接。
- 复制图文信息时保留 /note/ 链接，不转换成 /video/。
- 评论仍复用原逻辑，用作品 ID 关联。TSV 字段名保持原样。
- 原 Excel 服务、工作台及批量导出实现不变。原工作台的链接输入仍按原有视频入口使用，本次只扩展页面悬浮采集的图文支持。

验证：
1. 用旧版真实扩展加载到 /note/7704627255955686009 的模拟页面，复现入口被隐藏。
2. 用修复版加载同一路径，确认入口显示、展开收起正常；真实剪贴板中保留图文 URL、首图封面、19 位 ID 和 3 条按点赞降序的评论（含 0 赞）。
3. 普通 /video/ 详情页同样通过上述实际扩展测试，原工作台仍能打开。
4. 原有 TSV 和浏览器交互测试再次通过：TOP20、去重、少量/空评论、表头开关、备用复制、切换作品防串数据、停止后复制已有结果。

测试使用本地模拟网络响应，未验证该真实作品的数据与评论可读性，不代表已在用户浏览器中完成安装验收。

更新：备份原 extension 文件夹，将本包 extension 内文件复制进去；在 chrome://extensions/ 中找到“抖音视频入表 · Video Sheet”，点击“重新加载”，确认版本 1.2.2，再刷新抖音图文页。只需更新 extension，无需启动或更换本地服务。
