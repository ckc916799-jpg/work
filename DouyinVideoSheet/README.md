# 抖音视频入表 · Video Sheet

当前版本：**1.2.4**。修复图文页未捕获首次请求时的字段补读，支持图片组件、页面已有数据和可见元素兜底。视频信息只复制数据行，不附带表头；字段“视频文案”改为“标题”，字段与数值在悬浮列表中展示；评论改为单个单元格的排序文本。具体用法以《安装与WPS使用说明.txt》为准。修复 /note/ 图文页无法显示悬浮入口；支持视频详情和图文详情。新增默认收起的页面悬浮窗，可分别复制视频信息与已读取范围内的高赞评论为 WPS 可粘贴的 TSV。使用前请阅读本包《安装与WPS使用说明.txt》，测试范围见《测试与更新说明.txt》。复制功能无需启动本地服务；原 Excel 流程及配套 1.2.0 服务保持不变。下面保留原 Excel 工作流说明。下载的封面图片显示在封面单元格内，并随表格行移动；“内容领域”是可下拉选择的字段，选项由你维护。可先在表格 D 列填入多个视频链接，再批量采集。保存时生成更新后的 Excel，并弹出“另存为”让你选择保存位置。**默认建议带时间的新文件名，避免反复覆盖原文件。**

这是一个**独立于“抖音摘录 · Douyin Notes”** 的浏览器插件，专门把抖音视频数据写入 Excel。两个插件可以同时安装、同时显示在浏览器工具栏。请保留两个不同的解压文件夹，不要把本包里的文件覆盖到旧插件目录。

本插件只做视频数据、评论采集和 Excel 写入；不包含旧插件的口播转写与 Markdown 保存。旧插件及其原有数据无需更改。

## 安装

1. 解压整个压缩包，保留顶层 `DouyinVideoSheet` 文件夹，放在固定位置。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，开启“开发者模式”，选择“加载已解压的扩展程序”，选中 **DouyinVideoSheet/extension** 文件夹。浏览器中会出现名称为 **抖音视频入表** 的新插件；旧的 **抖音摘录** 仍可保留。
3. 在本包的 **DouyinVideoSheet/local-service** 文件夹双击 **Setup-Excel.bat** 安装 Excel 依赖，然后双击 **Start-Service.bat**。新服务使用本机 `127.0.0.1:18766`，旧插件仍使用它原来的 `18765`；两者可以同时运行。
4. 打开本包 `local-service/connection-token.txt`，复制连接码到新插件页面的“本地服务连接设置”，点“保存并连接”。这个连接码与旧插件的连接码分开。

安装需要 Python 3.9–3.13 和网络。脚本会尝试寻找本机 Python，依赖默认从清华大学 TUNA 的 PyPI 镜像安装；也可在 PowerShell 中运行 `setup.ps1 -PackageIndex 'https://pypi.org/simple'` 使用官方源。Excel 文件始终由你在浏览器选择，本地服务只在电脑内处理文件；封面缩略图需要从抖音图片地址下载。

## 使用

1. 在新插件页面粘贴抖音视频链接或分享文字，点击“打开链接并读取”；也可以直接在抖音视频详情页点击 **抖音视频入表** 图标。
2. 在抖音页面展开评论区。回到新插件点击“开始／继续采集”。界面实时显示已读取的一级评论数量，按点赞数取前 20 条；可选择采集上限、最长用时，也可中途停止后继续。
3. 点击“选择现有 Excel”或“新建 Excel”，选择工作表，检查写入预览，点击“生成并保存更新后的 Excel”。浏览器弹出“另存为”后确认保存位置；请保留更新后的文件，下次继续采集时选择它。同一视频再次写入同一工作表时会更新原行。
4. 打开保存的 Excel，切换到 **内容领域选项** 工作表，在 A2、A3 等单元格填入自己的领域名称（最多 200 个）；回到 **视频数据采集** 工作表，在 **内容领域** 列（K 列）下拉选择。隐藏的 J 列用于保存视频 ID。你的选项和已选领域在后续采集时会保留。

### 批量录入链接

1. 点击“下载批量链接模板”，在模板的 **D 列“视频链接”** 从第 2 行起每行填一个抖音视频链接，保存 `.xlsx` 文件。也可在本插件之前生成的表格末尾继续填链接。
2. 回到插件，选择刚保存的 Excel 和工作表，点击“读取待采集链接”。插件只找链接非空、隐藏的视频 ID 仍为空的行；每次处理前 20 行。已经处理过的行不会重复采集。
3. 选择每条视频的评论采集上限和最长用时，点击“开始批量采集”。插件逐条打开视频，尝试展开并滚动评论区，按点赞数选前 20 条，填回原来的链接行；每条的结果和失败原因会显示在页面中。
4. 本轮结束后只弹出**一次**“另存为”。若中途停止或部分视频失败，已完成的行仍可保存；下次选择更新后的文件继续处理空白行。保存窗口取消后可点“保存已采集结果”重试。

批量采集依赖抖音页面正常返回视频与评论；如果某条需要登录、验证，或后台标签页被浏览器暂停，该行会显示失败，其他行继续处理。批量默认每条最多 1000 条评论、90 秒，可在界面调整；20 条链接可能仍需较长时间。前 20 名只针对实际读取到的评论。

如果选中文件后显示“读取失败”，先看选择按钮下方的具体原因。常见情况是本插件的本地服务尚未启动，或新插件使用了旧插件的连接码：请运行本包 `local-service/Start-Service.bat`，在“本地服务连接设置”粘贴**本包**的 `connection-token.txt`，再点“重新读取工作表”。文件名会在选中后立即显示，不必重新选择文件。

从旧版更新时，先在**当前正在使用的 DouyinVideoSheet/local-service** 文件夹运行 **Stop-Service.bat**，再把本包解压覆盖到原来的 `DouyinVideoSheet` 目录，运行新版 **Start-Service.bat**，最后在浏览器扩展管理页点击“重新加载”。新本地服务需要 1.2.0；原有连接码和 Python 环境会保留。旧的“抖音摘录”插件及其服务无需改动。

每条视频一行，列为封面、视频标题、作者、视频链接、点赞数、评论数、收藏数、分享数、高赞评论前 20 条和内容领域。评论合并在一个多行文本格中；视频 ID 位于隐藏列，用于避免同一视频重复生成新行。旧版采集表在下次写入时会自动补上“内容领域”列。封面下载失败时保留可点击的封面链接。未知数字留空。**不保存视频文件、数据截图、已读取评论数或覆盖状态。**

封面采用 Excel 图片对象，放在 A 列单元格的范围内并设置为随单元格移动及调整，图片像素保存在文件里；这是兼容旧版 Excel 和 WPS 的方式。它与新版 Excel 的“放置在单元格中”图片类型不同。请先用你常用的 Excel 或 WPS 版本打开一个测试文件，确认图片与下拉选项的显示效果。

选择已有 `.xlsx` 文件时，可以使用空白工作表或本插件创建的工作表。其他结构的工作表会提示在更新版文件中新建“视频数据采集”工作表；原有工作表会保留。浏览器普通文件选择器只给插件读取权限，因此更新后的文件通过“另存为”保存，不会自动改动你选中的原件。Chrome 对手动选择覆盖已有文件时出现的权限确认由浏览器控制；插件默认建议带时间的新文件名，避免这一情况。表格上限为 25MB；Excel 单个文本格最多 32767 字符。

评论来自抖音网页实际返回的数据；若评论未完全加载，前 20 名是**已读取范围内**的排序，不能保证是整条视频的全局前 20 名。抖音页面要求登录或验证时，需要在原网页完成。浏览器更新或抖音页面结构变化后，可能需要刷新视频页并重新采集。

## 与旧插件的隔离

- 浏览器显示名称不同，安装目录不同，扩展身份和设置分开。
- 页面数据观察使用独立标记和通信通道；旧插件的数据不会进入新插件。
- 本地服务使用独立端口 `18766`、独立连接码和独立安装目录。新插件的“停止服务”只操作新服务；旧插件的 `18765` 服务不会被关闭。
- 同时启用时，两个插件都会读取同一抖音页面的数据；只有你点击某个插件的采集按钮时，该插件才会滚动评论区。建议不要在两边同时启动自动采集。

若要关闭新服务，双击本包 `local-service/Stop-Service.bat`。卸载新插件不会删除旧插件或旧插件导出的文件。
